# 덕천초 체험학습 기안문 생성기

항목을 입력하면 학교 밖 체험학습 기안문을 자동으로 완성해 주는 웹 앱입니다.
완성된 내용은 클립보드로 복사해 에듀파인에 붙여넣거나, 문서 파일로 내려받을 수 있습니다.

## 기술 스택

- React 18 + Vite
- Tailwind CSS
- lucide-react (아이콘)
- JSZip (`.hwpx` 문서 패키징)

## 실행 방법

```bash
npm install      # 의존성 설치
npm run dev      # 개발 서버 실행 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 주요 기능

- 관련 근거 / 행사명 / 대상 학년(다중 선택) / 학생 수 / 일시 / 장소 / 사전 안전 지도 날짜 입력
- 입력 즉시 갱신되는 실시간 기안문 미리보기
- **텍스트 복사**: Clipboard API 우선, 미지원 환경에서는 자동 폴백
- **한글파일 다운로드**: 본문을 한글 `.hwpx`(OWPML) 문서로 내려받기
  - 굴림체 12pt, 양쪽 정렬(줄간격 160%)이 적용되며, 한글에서 열어 본문을 복사해
    에듀파인·한글 공문 양식에 붙여넣으면 됩니다.
  - 한글에서 바로 열리도록 검증된 빈 HWPX 템플릿(`src/hwpx.js`)을 기반으로,
    `mimetype` 무압축 선두 저장 등 OWPML 패키지 규격을 준수합니다.
- **가정통신문 한글파일 다운로드**: 원본 가정통신문 양식(`.hwpx`)을 그대로 보존한 채 내용만 채움
  - 원본 파일의 머리글 이미지·표·서식을 100% 유지하며(`src/gtongsin.js` 에 원본을 템플릿으로 내장),
    `section0.xml` 안의 자리표시자 런만 폼 입력값으로 치환합니다.
  - 입력한 **행사명·대상 학년·일시·장소**를 자동으로 채우고(일시의 연도 오타 `2025`도 교정),
    발행일·담당자·제출 마감일 등 입력칸이 없는 항목은 자리표시자(`○`)로 남겨 한글에서 채우면 됩니다.
- 복사·다운로드 전 필수 입력값 검증

### 참여 학생 수 입력 규칙

- 숫자만 입력 → `대상 학년 + OO명`으로 자동 조합 (예: `1, 2학년 20명`)
- "학년"을 포함해 입력 → 입력한 문구를 그대로 표기 (예: `1학년 8명, 2학년 12명`)
